# MacroKeyboard ⌨️

一个基于 C# / WPF 的键盘宏录制与触发软件，支持全局快捷键绑定、鼠标事件录制、系统托盘常驻。

## 功能特性

- **录制宏**：按 `F9` 开始/停止录制键盘和鼠标事件
- **回放宏**：按 `F10` 回放/停止当前选中的宏
- **紧急停止**：按 `Esc` 立即停止录制或回放
- **自定义触发键**：为每个宏绑定独立的全局快捷键，随时触发
- **回放速度**：0.25x ~ 4x，以及"最快（无延迟）"
- **重复次数**：指定重复次数，0 为无限循环
- **鼠标录制**：可选录制鼠标移动、点击、滚轮事件
- **浮动提示**：宏触发/录制时屏幕左上角显示持久 Overlay 提示
- **系统托盘**：关闭窗口最小化到托盘，全局快捷键仍然有效
- **持久化存储**：宏自动保存到 `%AppData%\MacroKeyboard\macros.json`
- **暗色主题**：现代化 WPF UI

## 系统要求

- Windows 10/11
- .NET 8.0 Runtime

## 构建

```powershell
dotnet build -c Release
```

## 运行

```powershell
dotnet run -c Release
# 或直接运行
.\bin\Release\net8.0-windows\MacroKeyboard.exe
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| F9 | 开始/停止录制 |
| F10 | 开始/停止回放 |
| Esc | 紧急停止 |
| 自定义键 | 触发绑定的宏 |

## 架构

```
┌───────────────────────────────────┐
│         MainWindow (WPF)          │
│  左栏: 宏列表  |  右栏: 编辑/事件  │
└──────────────┬────────────────────┘
               │
┌──────────────▼────────────────────┐
│          核心引擎                  │
│  GlobalHookManager  ← Win32 低级钩子
│  MacroRecorder      ← 事件录制
│  MacroPlayer        ← SendInput 回放
│  MacroStorage       ← JSON 持久化
└───────────────────────────────────┘
```
